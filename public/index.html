How to read these plots

For each metric and option side, select the four highest strikes at the reference snapshot. At every plotted minute, divide each selected strike’s value by the highest value across all available strikes in that snapshot. The denominator changes with time; the four selected strikes stay fixed until the reference snapshot changes. Zooming does not reselect strikes.

Legends list strike prices from highest to lowest. Dotted markers show the first valid observation and each subsequent re-entry of the reference leader at 100%, including ties. These are sampled one-minute observations, not exact exchange event times. Click a legend item to hide a line; double-click to isolate it. Drag to zoom, use the toolbar to pan, double-click to reset, or download a PNG.

Negative OI changes are treated as zero. Missing values, all-zero denominators and stale source snapshots appear as gaps. Stale source snapshots are excluded from plotted values. Stability hover shows HH:MM once, followed by strike and percentage. ATM comparison hover includes the actual source timestamp. Data units are preserved from AOC; percentages do not require lot conversion.
